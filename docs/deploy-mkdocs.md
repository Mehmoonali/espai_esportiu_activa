# DEPLOY.YML I MKDOCS.YML

## Què és deploy.yml?

L'arxiu **deploy.yml** és el responsable de publicar automàticament la web a GitHub Pages cada vegada que fem canvis al repositori.


---

## Què és mkdocs.yml?

L'arxiu **mkdocs.yml** és el fitxer principal de configuració de MkDocs.

Aquest fitxer permet configurar el nom de la web, el menú de navegació, el tema visual i altres opcions del projecte.

### Exemple de canvi

Hem canviat el nom de la web i hem afegit noves pàgines al menú per adaptar-lo al nostre projecte.
